# Языки интерфейса (i18n)

Исходные строки — **английские**. Переводы лежат в каталогах `translations/cn_diag_tool_<lang>.ts`.
Приложение читает `.ts` напрямую через `i18n.TsTranslator` — **`lrelease` не нужен**.
`en` — базовый язык (каталога для него нет).

## Как добавить новый язык

1. **Зарегистрировать код языка** в `i18n.py`:
   ```python
   LANGUAGES = {
       'en': 'English',
       'ru': 'Русский',
       'fr': 'Français',   # код: название, как оно показывается в меню
   }
   ```
2. **Создать/обновить каталог** (сгенерирует `translations/cn_diag_tool_fr.ts` со всеми сообщениями,
   пока помеченными `type="unfinished"`):
   ```bash
   ./translations/update.sh fr
   ```
3. **Заполнить переводы** — откройте `.ts` в Qt Linguist (если установлен) или правьте XML вручную;
   впишите текст в `<translation>`. Непереведённые сообщения (или `type="unfinished"`) отображаются
   английским исходником.
4. **Проверить:** запустить приложение → `Config → Language → Français`.
   Язык сохраняется в `QSettings` (`Language`) и применяется с авто-перезапуском.

Стандартные кнопки диалогов Qt (Yes/No/OK/Cancel, файловые диалоги) переводятся автоматически,
если рядом есть `qtbase_<lang>.qm` — PyQt6 поставляет их; специальных действий не требуется.
Для французского — `qtbase_fr.qm`.

## Обновление после изменения строк

```bash
./translations/update.sh        # обновит все существующие каталоги
./translations/update.sh ru fr  # только указанные
```
Скрипт прогоняет `pylupdate6`, добавляет новые строки (unfinished) и удаляет устаревшие.

## Где какие строки

- **Экраны Qt Designer** (`ui/*.ui`) — контекст = имя класса формы (`MainWindow`, `Dialog`, ...).
  `pylupdate6` не видит alias `_translate(...)` в сгенерированных `.py`, поэтому строки берутся
  именно из `.ui`, а не из `cn_diag_tool_ui.py`.
- **Python** — `self.tr("...")` (контекст = класс) или `QCoreApplication.translate("Ctx", "...")`.
- **`LABELS`** строится до появления переводчика, поэтому исходники обёрнуты в
  `QT_TRANSLATE_NOOP("LABELS", "...")`, а переводятся в точках использования через `tr_label()`.
- Сообщения логов намеренно **не переводятся**.
